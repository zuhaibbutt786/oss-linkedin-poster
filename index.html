⚠️ Security Notice about your keys

You shared a LinkedIn Client ID and what appears to be a Client Secret / token in chat. Immediately regenerate your Client Secret in the LinkedIn Developer Portal because it is now public.

Never put Client Secret or Access Tokens in a public GitHub Pages site or any client-side JavaScript. For true automation use GitHub Actions + repository secrets, or a serverless function (Vercel / Netlify / Cloudflare Workers).
